## 🚀 How to Host on GitHub Pages (Step-by-Step Guide)

You can launch your live portfolio website on GitHub Pages for free in **under 3 minutes** using just your browser (no command line required)!

### Method 1: Using the GitHub Website (Easiest - Drag & Drop)

1. **Sign in to GitHub**:
   - Go to [github.com](https://github.com) and log in.

2. **Create a New Repository**:
   - Click the green **"New"** button (or the `+` icon on top right -> **New repository**).
   - **Repository name**: Type `portfolio` (or `navya-finance-portfolio`, or `<your-username>.github.io`).
   - Set visibility to **Public** (required for free GitHub Pages).
   - Click **"Create repository"**.

3. **Upload Your Files**:
   - On your repository page, click **Add file** -> **Upload files**.
   - Drag and drop all the contents inside this `ProjectN` folder:
     - `index.html`
     - Folders: `css`, `js`, `assets`, `Infosys`, `Real Estate`, `Blinkit analysis`
   - Scroll down and click the green **"Commit changes"** button.

4. **Turn On GitHub Pages**:
   - In your repository, click the **Settings** tab (gear icon at top).
   - In the left sidebar, click **Pages** (under "Code and automation").
   - Under **"Build and deployment"** -> **Source**: Select **"Deploy from a branch"**.
   - Under **Branch**: Select `main` (or `master`) and folder `/ (root)`.
   - Click **Save**.

5. **Your Live Website is Ready!**
   - Wait 1-2 minutes. Refresh the GitHub Pages settings page.
   - You will see your live URL:
     `https://<your-username>.github.io/portfolio/`
   - You can copy this link and paste it directly into your Resume, LinkedIn profile, or placement applications!
